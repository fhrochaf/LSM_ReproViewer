LARSIM ReproChecker

Reproducible landslide mapping studies

Automated landslide mapping publications, from 2020 to 2025, retrieved from Scopus, whose methods were assessed as reproducible or partially reproducible: the code and data needed to reproduce the results are available, fully or in part.

This project was developed using LSM_ReproChecker, available at github.com/fhrochaf/LSM_ReproChecker.
